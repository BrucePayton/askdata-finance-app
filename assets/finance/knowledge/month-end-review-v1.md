# 月结与报告复核清单

文档编号：FIN-CLOSE-001；版本：v1；责任角色：总账与财务分析岗；状态：测试用草案，未经企业审批，不是生效制度。

## 报告前检查

1. 确认主体、会计期间、币种、单位和数据来源。
2. 确认月结状态与预算口径；底表缺少月结状态时不得声称已关账。
3. 验证收入、成本、费用和现金勾稽，不平项明确列示，不自动调整业务数据。
4. 审查 SQL 是否只读、时间和主体过滤是否完整。
5. 核对图表与明细、合计与分项、百分比分母以及舍入差额。

## 知识运营流程

文档依次经历草拟、财务复核、批准、生效、废止。上传和索引状态只表示技术处理情况，不代表审批通过。
每份文件保留文档编号、版本、适用期间、责任角色、状态与变更原因。历史版本保留供历史报告追溯，不得以当前新口径静默重算已发布报告。

## 发布要求

报告正文需要管理摘要、关键指标、对比图、明细表、证据与限制，不得把组件 ID、JSON 元数据或生成计划当作交付正文。
保存成果应回显平台成果 ID、所属工作空间及来源会话；相同工作空间中，专业版与底座查询到的成果 ID 应一致。
